# Projeto_Pokedex

Este projeto é uma aplicação desenvolvida com React como parte de uma atividade para praticar o uso da biblioteca. O objetivo principal foi aprimorar meus conhecimentos em React, explorando conceitos como estado, componentes e gerenciamento de eventos.

##Sobre o Projeto
A aplicação é uma Pokedex simples, onde é possível consultar informações sobre diversos Pokémon. A interface permite ao usuário buscar, visualizar e interagir com os dados relacionados a cada Pokémon.

###Considerações
Este projeto foi desenvolvido como exercício de aprendizado de React, com foco em entender conceitos básicos da biblioteca.
A responsividade não foi um foco principal, visto que o objetivo era explorar a parte de frontend com React. Em projetos futuros, pretendo melhorar a responsividade e aprimorar o design.
